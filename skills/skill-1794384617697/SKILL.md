# 跨助手传递文件

适用：一个助手拿到用户附件或产出文件后，另一个助手要继续处理。

## 输入
- 源文件的当前路径
- 接收方（另一个助手）
- 共享目标路径（位于共享工作区，按任务命名）

## 步骤
1. 不要假定另一个助手能读取你的私有附件目录或仅本助手可见的路径。
2. 把文件复制到共享工作目录（例如共享原料目录下的任务子目录）。
3. 校验目标文件存在，并核对大小或校验和与源文件一致。
4. 只把校验过的共享路径告诉接收方，让它直接读该文件；不要要求用户重传，也不要让对方全盘搜索。
5. 若复制或校验失败，停下来如实报告，不要用错文件接手。

## 验证
- 接收方能直接打开共享路径中的文件
- 大小或校验和与源文件一致

## 常见失败
- 只把私有附件路径发给对方，对方读不到，任务停在找图
- 走附件消息通道失败后没有改走共享目录
- 未校验就让对方开始，读到空文件或错文件

## 边界
- 只传该任务需要的文件，不要抄贝无关私人内容
- 不要把私人文件传到外部服务或公开仓库
