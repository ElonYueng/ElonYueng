# 未授权材料先脱敏再分发

适用：用户发来录音、转写或纪要，要求整理成学习资料或可公开图文，但这些材料默认没有二次传播授权。

## 输入
- 源材料（录音、转写或纪要）
- 用途：学习资料、图文草稿，或两者
- 是否允许发布：默认否

## 步骤
1. 把原文视为无二次传播授权，除非用户明确授权传播某些范围。
2. 如需转写，只在本地完成；不要把录音或转写全文交给云端模型。
3. 只提炼可公开的方法、框架或纪律，写成一份脱敏简报：去掉原话、机构名、产品名、人物名和未公开观点。
4. 交给其他助手做学习资料或出图时，只给这份简报和约束说明；不要把原文路径发给对方并让他们去读全文。
5. 产出先给用户看；未经明确授权不要发布，也不要导流到私人聊天。

## 验证
- 简报和下游产出里没有原文原话，也没有可识别的机构、产品或人物
- 下游助手只读了简报，没有去读录音或转写全文

## 常见失败
- 把全文送进云端模型
- 只把原文路径发给其他助手，对方读到了未授权全文
- 产出里出现原话或点名
- 未等用户确认就发布

## 边界
- 用户明确授权传播某段材料时，按当次授权范围处理
- 不把学习资料或方法图写成投资建议
- 不改变用户已确认的发布红线
