# 豆包播客 → 小红书静图视频

目标：一个话题跑完 出题 → 豆包长对谈 → 豆包自动生成播客 → 下载 WAV → 静图海报+中部音波+逐句字幕 9:16 视频 → 小红书发布。

## 输入
- 话题或当天可用的脱敏材料
- 钩子问句标题（≤20 字）和一个强调词
- 当次是否授权公开发布（默认否）
- 工作目录（含 `raw/`、`video/`、`xhs/`、`log.md`）

## 省 token 原则
- 浏览器只做必须做的三件事：豆包对话与下载、小红书上传发布。其余全部用本地脚本。
- 复用已有脚本（转写、海报、音波、字幕、合成），只改标题和输出目录，不重写代码。
- 浏览器子任务一次一段、给精确 URL 和停止条件；不要让它重复截图。

## 步骤
1. **选题**：从当天材料或选题库挑一个，只讲方法、不点名产品、不荐股。写一个钩子问句标题（≤20 字）和一个强调词。
2. **豆包长对谈**（已登录的豆包网页版新对话）：发一段要求「两位主持人（理性框架派 / 普通投资者）围绕〈话题〉做有深度的双人对谈，覆盖误区、证据、纪律、反例」的长提示，再追问 1 轮深化。对话够长后，豆包会自己插入播客播放器；没出现就再追问一轮。网页版不一定能在消息「更多」里找到「听播客」，以对话里实际出现的播放器为准。
3. **下载音频**：点播放器「下载」，WAV 约 20MB+/8 分钟，需等约 1 分钟；以浏览器下载完成为准，拷到 `raw/` 并用 ffprobe 核对时长。
4. **合成视频**（本地，不进浏览器）：
   - 本地转写拿词级时间戳；字幕把平台名替换成「本期节目」，修明显错别字。
   - 代码绘制海报（深色科技风、标题+强调色、底部「方法科普，不构成投资建议」），不用 AI 生图。
   - 中部音波 + 底部逐句字幕，1080×1920、30fps、H.264+AAC、loudnorm -16 LUFS；抽 3–5 帧自检。
5. **小红书发布**（创作服务平台，已登录）：上传视频、设封面、填标题与正文（结尾带免责声明和 3–4 个话题标签，不用荐股类标签），打开「笔记含AI合成内容」，点发布一次；在笔记管理里确认状态（可能审核中）。
   - 直接上传后发布，不走草稿箱：草稿只存在浏览器本地，重新打开时视频和封面会丢，得重传。
   - 网络慢时上传和封面对话框会卡，等加载完再操作；封面用「上传封面」选本地海报。
6. **复盘**：在 `log.md` 记录耗时、卡点、审核结果；下次先改最大的卡点。

## 验证
- WAV 存在，时长与播放器显示一致
- 成片为竖屏 1080×1920，字幕中不出现平台名
- 若已授权发布：笔记管理中能看到已发布或审核中，且已勾选 AI 合成声明
- `log.md` 已记本轮卡点

## 常见失败
- 只发短问答，对话不够长，播客播放器不出现
- 下载未等够约 1 分钟就判为失败
- 把成片存进草稿箱，重新打开后视频和封面丢失
- 在 Linux 云环境安装非官方客户端或模拟器对抗红线
- 未登录就去点发布，或网络慢时没等对话框加载完

## 合规与边界
- 只讲方法；不点名基金/个股代码，不承诺收益，不导流微信。
- 未授权的内部纪要不全文喂给豆包，只给脱敏后的方法要点。
- 发布前须有用户明确授权（单次或已说明范围的长期授权）；遇登录、验证码、扣费就停下报告。
- 密钥、验证码不进聊天；不装来源不明的软件。
