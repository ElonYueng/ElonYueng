# 多助手共用桌面轮流用

适用：同一台云电脑上，一个助手正在用浏览器（例如等待网页端生成音频、填发布表单），另一个助手也需要桌面（登录、发布、下载）。

## 输入
- 当前占用者是谁、做到哪一步
- 我需要桌面做什么、大约多久
- 哪些标签页正在服务端生成或填了一半，不能动
- 用户定的发布时段或优先级

## 步骤
1. 先看占用方的工作日志或直接问状态，不要直接开浏览器任务抢屏。
2. 请对方在安全点让出：说明我要做什么、需要多久、哪些标签页请保留。
3. 对方回报当前步骤和不能碰的页面后再开始；正在生成的页面保持打开，不刷新、不关闭。
4. 只在新标签页或指定标签页里操作，不碰对方的表单和下载。
5. 做完立刻通知对方继续，并说明我留下了哪些标签页。
6. 两件事抢同一时段时，按用户定的发布时段排先后；不确定就问用户，不拿对方的转述当用户批准。

## 验证
- 两边任务都能继续，没有丢失的生成进度或表单
- 让出和交还都有一句明确回报

## 常见失败
- 两个浏览器子任务同时跑，互相抢鼠标和焦点
- 刷新或关闭了正在生成的页面，服务端进度丢失
- 把另一个助手转述的话当成用户的发布授权

## 边界
- 只适用于共用同一个桌面的情况，各自独立的桌面不需要排队
- 不改变任何一方的发布授权和红线
