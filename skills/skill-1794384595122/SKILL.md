# 定时任务回主对话执行

适用：例程被定时触发后，需要读取用户或其他助手的聊天记录，或依赖其他仅主对话可用的工具。

## 输入
- 本轮固定时间窗口（起止时间）
- 要覆盖的对话范围（逐个助手 ID，不要只搜当前会话）
- 上一轮成功游标（若有）

## 步骤
1. 定时触发后，在本助手自己的主对话里完成复盘与落盘，不要把读聊天、写 Skill、推进游标交给隔离运行或后台执行器。
2. 逐个指定可访问的助手 ID 做聊天检索，按时间窗口分页；空结果只表示工具未返回记录，不能推定对方没有对话。
3. 若本轮发现读聊天工具不可用，不要把失败当成终态，立刻回主对话按同一窗口做完。
4. 只有主对话验收成功后才推进该范围游标；覆盖失败时保留旧游标并记录缺口，不得跳过未读内容。
5. 不直接读取聊天数据库，也不声称覆盖了不可访问的会话。

## 验证
- 主对话里实际读到了各目标助手在窗口内的可见记录，或明确记录了缺口
- 游标与真实覆盖一致，未读段不被标成已完成

## 常见失败
- 把读聊天交给隔离运行或执行器，对方报工具不存在，连续多天零覆盖
- 把当前会话空结果当成全部助手都没有新对话
- 工具失败后仍推进游标，导致下次漏读

## 边界
- 不改变例程的业务规则、时间和授权范围，只约束执行位置
- 不要用读取聊天数据库或其他未授权途径取代
