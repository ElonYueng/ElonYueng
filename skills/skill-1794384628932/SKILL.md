# 停止后台任务勿误伤同伴

适用：要取消自己发起的上传、浏览或后台任务，避免重复操作或抢占共享桌面。

## 输入
- 要停的那个后台任务 ID
- 停止原因（例如对方已完成、避免重复）

## 步骤
1. 只把自己发起、需要取消的那个任务 ID 传给停止工具。
2. 不要使用会带停其他助手、同行任务或对方当前回合的全局停止，除非用户明确要求停止全部当前工作。
3. 停止后核对返回：只有自己的目标任务被停掉，才算完成。
4. 若误停了其他助手的回合，立刻告诉对方：这是误操作、不要重做已完成的工作，并向用户如实说明。

## 验证
- 返回结果里，被停的只有自己要取消的那个任务
- 其他助手的当前回合仍在

## 常见失败
- 使用全局停止来取消自己的一个上传或浏览任务，连带取消了其他助手的当前回合
- 误停后不说明，对方误以为要重做已完成的交付

## 边界
- 用户明确要求停止全部当前工作时，遍布停止仍按该要求执行
- 不要为了补救误停而重新发起已经完成的外发或上传
