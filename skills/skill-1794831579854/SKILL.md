# 云电脑遇地区限制时改走本机设备码登录

目标：在云电脑登录对访问地区有限制的官方网站或命令行工具时，先确认失败原因是地区限制，再改用官方设备码，由用户在自己电脑完成授权；验证码和密码不进聊天。

本技能与「国内平台登录看网络出口」方向相反：那边是国内平台需要先确认走国内网络；这边是云电脑所在地区不被目标服务支持。

## 适用
- 云电脑浏览器打开登录页，提示「地区不支持」或同类地区限制，且没有账号密码框。
- 云电脑上的官方命令行工具登录失败，报地区限制，或浏览器登录走不通，但该服务提供设备码 / 设备登录。

## 不要做
- 不要反复刷新登录页，也不要为了同一登录反复切换「通过用户电脑上网」。
- 不要装来路不明的代理，不要重置云电脑，不要改系统网络配置。
- 不要把一次性验证码、密码或密钥发到聊天，也不要朗读、复制到对话里。
- 不要把「用户在自己电脑已经登录了该服务的官网」当成云电脑上的工具已经登录。
- 未获用户同意，不要提交登录信息或扣费。

## 步骤
1. **确认原因**：看清当前页面或命令的报错和网址，确认是地区限制，而不是账号、密码或验证码错误。此时不要提交任何登录信息。
2. **先判断有没有设备码**：若该服务提供官方设备码 / 设备登录（在云电脑终端发起登录，得到一组短码，到官方设备登录页输入），优先走这条，而不是继续用云电脑浏览器打开登录页。
3. **发起设备码**：在云电脑终端运行该服务的官方登录命令，把终端放到屏幕前面。请用户打开云电脑屏幕查看当前验证码，并在**自己电脑**打开官方设备登录页输入、确认授权。说明验证码的大致有效期；过期就重新发起，不要沿用旧码。
4. **核对云电脑登录态**：用户说「已登录」之后，必须在云电脑上运行该工具的官方状态命令，确认云电脑侧已经登录，再开始依赖该登录态的任务。若状态仍是未登录，提醒用户：需要在设备登录页输入云电脑屏幕上的那组码，而不是只登录官网。
5. **「通过用户电脑上网」只试一次**：若用户自己的电脑可以打开该登录页，可以打开「通过这台电脑上网」后再试一次网页登录。若登录页仍被地区限制拦截、没有输入框，立刻停这条路，改走第 3 步，不要再切换网络重试。

## 验证
云电脑上的官方状态命令显示已登录后，再执行需要该登录态的任务。只听到用户说自己电脑已登录，不能算完成。

## 常见失败
- 网页登录持续地区拦截且没有输入框：停止网页登录，改设备码。
- 用户只登录了官网，没有在设备登录页输入云电脑当前验证码：云电脑仍然未登录；重新展示当前码并说明区别。
- 验证码过期，或云电脑换票失败：重新发起一轮设备码，请用户输入新码。
- 出现扣费、验证码无法完成、账号限制：停下，带当前页面或报错如实报告。

## 边界
只用于官方支持设备码或设备登录的服务。没有设备码、必须在同一浏览器里完成的登录，不适用本技能。本技能不解决国内平台需要国内网络出口的问题。
