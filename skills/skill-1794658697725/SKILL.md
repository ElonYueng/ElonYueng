# 国内平台登录看网络出口

适用：云电脑的默认网络出口在境外，登录或发布国内平台时出现网络异常、接口超时，或登录后很快被踢下线。

## 输入
- 要登录的平台和创作者后台地址
- 浏览器当前是否在走用户自己电脑的网络（用户电脑是否在线）
- 账号凭据已存进保险库（用表单填写，不进聊天）

## 步骤
1. 登录前先确认浏览器是否在走用户那台国内电脑的网络；用户电脑离线时，提醒用户这次登录很可能失败。
2. 打开官方创作者后台登录页，优先扫码；需要密码时用保险库表单填写。
3. 出现「网络异常」「系统繁忙」、接口超时，或点了登录无报错也无反应：按网络出口问题处理，不要反复重试账号密码。
4. 请用户让自己的电脑上线后再试一次。
5. 登录成功后留意：用户电脑一离线，出口切回境外，登录态可能被踢；发布前先确认仍是登录状态。
6. 长期方案只给官方支持的做法：让一台常开的国内设备注册为用户的电脑，把流量改走它；不要自己装来路不明的代理。

## 验证
- 创作者后台首页显示登录账号
- 发布前重新打开上传页，确认没有回到登录页

## 常见失败
- 用户电脑离线时在境外出口上反复登录
- 登录成功后出口变化，被踢回扫码页
- 把出口问题误判成账号密码错误

## 边界
- 平台的风控规则会变，以当次页面提示为准
- 不绕过验证码、不改变平台账号设置
